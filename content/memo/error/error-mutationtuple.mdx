title: 'Apollo useMutation 구조 분해 오타 에러'
date: 2023/05/15
tags: [Memo, 에러]
---

## 1. 에러 메시지

```txt
'MutationTuple<any, OperationVariables, DefaultContext, ApolloCache<any>>' 형식에 'deletePostMemo' 속성이 없습니다.
```

## 2. 원인

`useMutation`은 객체가 아니라 **배열(튜플)** 을 반환한다. 그런데 `{}`로 구조 분해를 해서, 반환값에 없는 `deletePostMemo` 속성을 꺼내려다 에러가 났다.

```tsx
// ❌ 객체 구조 분해 → 에러
const { deletePostMemo } = useMutation(DELETE_POST_MEMO)

// ✅ 배열 구조 분해
const [deletePostMemo] = useMutation(DELETE_POST_MEMO)
```

## 3. 해결

**`{}`를 `[]`로 고친다.** 단순 오타였다.

```tsx
export default function MyMemo() {
  const { data } = useQuery(FETCH_POST_MEMOS)
  const [deletePostMemo] = useMutation(DELETE_POST_MEMO)

  // 저장된 메모 단일 삭제
  const onClickDeleteMemo = async (event: MouseEvent<HTMLButtonElement>) => {
    try {
      await deletePostMemo({
        variables: {
          memoId: event.currentTarget.id,
        },
        refetchQueries: [{ query: FETCH_POST_MEMOS }],
      })
      Modal.success({ content: '메모가 삭제되었습니다.' })
    } catch (error) {
      if (error instanceof Error) Modal.error({ content: error.message })
    }
  }

  return <MyMemoUI data={data} onClickDeleteMemo={onClickDeleteMemo} />
}
```
