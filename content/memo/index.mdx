## 5. 개발 도구

- [Creately](https://creately.com/)

- [ERD Editor](https://marketplace.visualstudio.com/items?itemName=dineug.vuerd-vscode) : VS Code 확장

### 5.3 API·데이터

- [jwt.io](https://www.jwt.io/) : JWT 토큰 디코딩

### 5.4 그 밖에 자주 쓰는 도구

- [regex101](https://regex101.com/) : 정규식 테스트와 설명
- [crontab.guru](https://crontab.guru/) : cron 표현식 해석
- [Carbon](https://carbon.now.sh/), [ray.so](https://ray.so/) : 코드를 예쁜 이미지로 만들기 (발표·블로그용)
- [Squoosh](https://squoosh.app/) : 브라우저에서 이미지 압축·변환 (WebP, AVIF)
