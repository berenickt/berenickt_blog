## 1. RxJS란?

- **R**eactive E**x**tensions for **J**ava**S**cript
- 시간에 따라 발생하는 값(이벤트, HTTP 응답, 타이머 등)을 **스트림(Observable)** 으로 다루는 라이브러리
- 배열을 `map`, `filter`로 다루듯, **비동기 이벤트도 연산자로 조합**할 수 있음
- Angular의 HTTP·폼, NestJS의 Interceptor·마이크로서비스 등에서 기본으로 사용
  - NestJS 예시는 [Interceptor](/backend/nestjs/28-interceptor) 참고

## 2. Promise와 비교

| 구분      | Promise                   | Observable                              |
| --------- | ------------------------- | --------------------------------------- |
| 값의 개수 | 하나                      | 0개 ~ 여러 개 (스트림)                  |
| 실행 시점 | 만들자마자 실행 (eager)   | `subscribe` 해야 실행 (lazy)            |
| 취소      | 불가능                    | `unsubscribe`로 취소 가능               |
| 조합      | `then`, `Promise.all` 정도 | 100개가 넘는 연산자(operator)           |

## 3. 핵심 개념

- `Observable`: 값을 흘려보내는 스트림 (생산자)
- `Observer`: 값을 받는 쪽, `next` / `error` / `complete` 세 가지 콜백
- `Subscription`: 구독 정보, `unsubscribe()`로 구독 해제
- `Operator`: 스트림을 변환하는 순수 함수, `pipe()` 안에서 연결
- `Subject`: 여러 구독자에게 같은 값을 동시에 보내는 Observable (이벤트 버스처럼 사용)

```ts
import { Observable } from 'rxjs'

const numbers$ = new Observable<number>(subscriber => {
  subscriber.next(1)
  subscriber.next(2)
  subscriber.complete()
})

const subscription = numbers$.subscribe({
  next: v => console.log(v), // 1, 2
  error: e => console.error(e),
  complete: () => console.log('끝'),
})

subscription.unsubscribe()
```

- 변수 이름 끝의 `$`는 Observable이라는 것을 나타내는 관례

## 4. 생성 함수

```ts
import { of, from, interval, fromEvent, timer } from 'rxjs'

of(1, 2, 3)                          // 나열한 값을 차례로
from([1, 2, 3])                      // 배열·Promise·이터러블을 Observable로
interval(1000)                       // 1초마다 0, 1, 2 ...
timer(3000)                          // 3초 뒤 한 번
fromEvent(document, 'click')         // DOM 이벤트
```

## 5. 자주 쓰는 연산자

```ts
import { interval, map, filter, take } from 'rxjs'

interval(1000)
  .pipe(
    filter(n => n % 2 === 0), // 짝수만
    map(n => n * 10),         // 10배
    take(3),                  // 3개만 받고 종료
  )
  .subscribe(console.log)     // 0, 20, 40
```

| 연산자                  | 설명                                                 |
| ----------------------- | ---------------------------------------------------- |
| `map`, `filter`         | 값 변환, 걸러내기                                    |
| `tap`                   | 값은 그대로 두고 로그 등 부수 효과만 실행            |
| `debounceTime`          | 입력이 멈춘 뒤 일정 시간이 지나면 마지막 값만 전달   |
| `switchMap`             | 새 값이 오면 이전 비동기 작업을 취소하고 새로 시작   |
| `mergeMap`              | 비동기 작업을 동시에 여러 개 실행                    |
| `catchError`            | 에러를 잡아 대체 값이나 다른 스트림으로 바꿈         |
| `takeUntil`             | 다른 스트림이 값을 내면 구독 종료 (메모리 누수 방지) |

## 6. 예제: 검색 자동완성

```ts
import { fromEvent, debounceTime, map, distinctUntilChanged, switchMap, from } from 'rxjs'

const input = document.querySelector('input')!

fromEvent(input, 'input')
  .pipe(
    map(e => (e.target as HTMLInputElement).value.trim()),
    debounceTime(300),             // 300ms 동안 입력이 없을 때만
    distinctUntilChanged(),        // 같은 검색어는 무시
    switchMap(q => from(fetch(`/api/search?q=${q}`).then(r => r.json()))), // 이전 요청은 버림
  )
  .subscribe(results => console.log(results))
```

- `switchMap` 덕분에 늦게 도착한 이전 검색 결과가 최신 결과를 덮어쓰는 문제가 생기지 않음
