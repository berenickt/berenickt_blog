## 1. Redis란?

- **Re**mote **Di**ctionary **S**erver의 줄임말
- 데이터를 메모리(RAM)에 저장하는 **인메모리 Key-Value 저장소**
  - 디스크 기반 DB보다 훨씬 빠름 (대부분 명령이 1ms 이하)
- 기본 포트: `6379`
- 주로 메인 DB 앞에 두는 **캐시**, 세션 저장소, 실시간 랭킹, 메시지 브로커 등으로 사용
- 2024년 라이선스가 바뀌면서, Linux Foundation 주도의 오픈소스 포크 **Valkey**가 등장 (명령어 호환)

---

## 2. 특징

- `빠른 속도`: 메모리에서 읽고 쓰며, 명령은 하나의 스레드에서 순서대로 처리
  - 그래서 `INCR` 같은 명령은 동시에 요청해도 원자적(atomic)으로 처리됨
- `다양한 자료구조`: 단순 문자열뿐 아니라 List, Set, Hash, Sorted Set 등을 지원
- `만료 시간(TTL)`: 키마다 유효 시간을 정해 자동 삭제 → 캐시·인증번호에 적합
- `영속성`: 메모리 데이터를 디스크에 저장하는 두 가지 방식
  - `RDB`: 일정 간격으로 전체 스냅샷 저장
  - `AOF`: 모든 쓰기 명령을 로그로 기록
- `복제·클러스터`: Replica, Sentinel(자동 장애 조치), Cluster(데이터 분산) 지원

## 4. 자료구조와 명령어

```bash
# String: 가장 기본, 숫자 증감도 가능
SET user:1:name "철수"
GET user:1:name
SET auth:code:010 "123456" EX 180   # 180초 뒤 자동 삭제
TTL auth:code:010                    # 남은 시간
INCR page:views                      # 1씩 증가 (조회수)

# Hash: 객체 하나를 필드별로 저장
HSET user:1 name "철수" age 20
HGETALL user:1

# List: 순서가 있는 목록 (큐/스택)
LPUSH jobs "job1"
RPOP jobs

# Set: 중복 없는 집합
SADD post:1:likes user:1 user:2
SCARD post:1:likes                   # 좋아요 수

# Sorted Set: 점수로 정렬되는 집합 (랭킹)
ZADD ranking 100 "철수" 200 "영희"
ZREVRANGE ranking 0 9 WITHSCORES     # 상위 10명

# 기타
KEYS *        # 운영 환경에서는 금지 (전체 탐색으로 서버가 멈출 수 있음) → SCAN 사용
DEL user:1
```

- 키 이름은 `대상:id:필드`처럼 `:`로 구분하는 것이 관례

## 5. 대표 활용 사례

- `캐시`: DB 조회 결과를 잠시 저장해 같은 요청은 Redis에서 바로 응답 (Cache-Aside 패턴)
  1. Redis에 데이터가 있으면 바로 반환
  2. 없으면 DB에서 조회 → Redis에 TTL과 함께 저장 → 반환
- `세션 저장소`: 서버가 여러 대여도 로그인 세션을 공유
- `인증번호·토큰`: TTL로 만료 처리 (Refresh Token, 이메일 인증 코드 등)
- `랭킹`: Sorted Set으로 실시간 순위
- `Rate Limit`: `INCR` + `EXPIRE`로 일정 시간당 요청 수 제한
- `Pub/Sub, Stream`: 메시지 전달, 작업 큐 (BullMQ 같은 큐 라이브러리가 Redis 기반)
- NestJS에서 캐시로 쓰는 방법은 [Cache](/backend/nestjs/40-cache) 참고

## 6. Node.js에서 사용하기

```bash
npm i ioredis
```

```ts
import Redis from 'ioredis'

const redis = new Redis(process.env.REDIS_URL ?? 'redis://localhost:6379')

async function getUser(id: number) {
  const cacheKey = `user:${id}`
  const cached = await redis.get(cacheKey)
  if (cached) return JSON.parse(cached)

  const user = await db.user.findUnique({ where: { id } })
  await redis.set(cacheKey, JSON.stringify(user), 'EX', 60) // 60초 캐시
  return user
}
```
