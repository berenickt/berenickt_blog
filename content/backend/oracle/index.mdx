## 1. Oracle Database란?

- Oracle사가 만든 **상용 관계형 데이터베이스(RDBMS)**
- 은행·공공기관·대기업 등 안정성과 대용량 처리가 중요한 곳에서 오래 사용됨
- 기본 포트: `1521`
- 유료 라이선스가 기본이지만, 학습·개발용 무료 버전 **Oracle Database Free**가 있음

---

## 2. 특징

- `PL/SQL`: SQL에 변수·조건문·반복문을 더한 Oracle 전용 절차형 언어
  - 프로시저, 함수, 트리거를 DB 안에서 작성
- `시퀀스(Sequence)`: 번호를 자동으로 발급하는 객체
  - (12c부터는 `GENERATED AS IDENTITY`로 자동 증가 컬럼도 지원)
- `RAC(Real Application Clusters)`: 여러 서버가 하나의 DB를 함께 처리하는 고가용성 구성
- `강력한 옵티마이저와 파티셔닝`: 대용량 데이터 처리에 강점
- 단점: 라이선스 비용이 높고, 다른 DB와 문법 차이가 꽤 있음

---

## 3. 다른 DB와 문법 차이

| 기능             | MySQL / PostgreSQL       | Oracle                                   |
| ---------------- | ------------------------ | ---------------------------------------- |
| 개수 제한        | `LIMIT 10`               | `FETCH FIRST 10 ROWS ONLY` (12c+), `ROWNUM` |
| NULL 대체        | `COALESCE`, `IFNULL`     | `NVL`, `COALESCE`                        |
| 문자열 타입      | `VARCHAR`                | `VARCHAR2`                               |
| 현재 시간        | `NOW()`                  | `SYSDATE`, `SYSTIMESTAMP`                |
| FROM 없는 SELECT | `SELECT 1;`              | `SELECT 1 FROM DUAL;` (23ai부터는 생략 가능) |

- Oracle은 빈 문자열(`''`)을 `NULL`로 취급하므로 주의

## 4. 기본 SQL

```sql
CREATE TABLE users (
  id         NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  email      VARCHAR2(255) NOT NULL UNIQUE,
  name       VARCHAR2(50)  NOT NULL,
  created_at DATE DEFAULT SYSDATE
);

INSERT INTO users (email, name) VALUES ('a@test.com', '철수');
COMMIT; -- Oracle은 기본적으로 자동 커밋이 아님

SELECT id, name, NVL(email, '없음') AS email
FROM users
ORDER BY id DESC
FETCH FIRST 10 ROWS ONLY;
```

## 5. 시퀀스

```sql
CREATE TABLE posts (
  id    NUMBER PRIMARY KEY,
  title VARCHAR2(200) NOT NULL
);

CREATE SEQUENCE post_seq START WITH 1 INCREMENT BY 1;

INSERT INTO posts (id, title) VALUES (post_seq.NEXTVAL, '첫 글');
SELECT post_seq.CURRVAL FROM DUAL; -- 마지막으로 발급한 값
```

## 6. PL/SQL 맛보기

```sql
CREATE OR REPLACE PROCEDURE rename_user (
  p_id   IN NUMBER,
  p_name IN VARCHAR2
) AS
BEGIN
  UPDATE users SET name = p_name WHERE id = p_id;
  COMMIT;
END;
/

-- 실행
EXEC rename_user(1, '민수');
```

## 7. 개발용으로 실행하기

- 공식 컨테이너 레지스트리: `container-registry.oracle.com`의 Oracle Database Free 이미지
- 또는 커뮤니티에서 관리하는 가벼운 이미지 `gvenzl/oracle-free`를 많이 사용

```bash
docker run -d --name oracle \
  -e ORACLE_PASSWORD=비밀번호 \
  -p 1521:1521 \
  gvenzl/oracle-free
```

- GUI 도구: SQL Developer(공식, 무료), DBeaver, DataGrip 등
